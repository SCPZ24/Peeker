# Feedback

> v2.0.0由于没有进行实机验证，出现了大量bug和feature不完整。


## CLI无法获悉

当前peeker CLI共能完好，但是Agent不可用。

输入
```bash
peeker --help
```
后，Agent只看得到peeker根指令的help。


我们应该在根help里进一步引导输入下一级指令工具的help。

并实现
```bash
peeker timer --help

peeker pusher --help

```
等多个子级帮助手册指令。


## 退出程序位置

当前`退出peeker`按钮在设置-关于。
应该把这个按钮放到设置-通用。


## “收敛态”被遮挡

当前只有timer功能有收敛态。（注意区分静息态，收敛态和展开态）

我发现发出消息提示后，重新回到timer收敛态时，似乎回到的收敛态太小了，导致timer收敛态部分内容会被遮挡，如[timer被遮挡](./blocked.png)。


## 延时触发机制

有用户反馈，鼠标一移动到静息或收敛态的岛上就会触发“展开为展开态”。

我们新增设置触发时长。在设置-通用中更改
时长为0表述鼠标一移动到热区就触发展开触发态。
时长为n表示鼠标移动到热区上，悬停n秒才展开触发态。



## scheduler UI问题

scheduler展开面板上，点击某个时间触发新建。
新建的框体中，以浅灰色底，白色输入框为色调。
但是UI上的文字也是白色的，输入框里预设占位和实际输入的文字也是篇白色。这就导致看不清。你需要调整为灰色。

同时，用户可以自由输入日程的颜色。我们应该改为只能选择预设好的固定几个颜色值。


## scheduler闪动问题

展开态-scheduler-点击时间点新增。
弹出“新增”面板后，用户鼠标移动到“新增”面板上，scheduler异常自动收敛为静息态。有时甚至会在静息态和展开态之间异常来回闪动，导致无法操作新增面板。
