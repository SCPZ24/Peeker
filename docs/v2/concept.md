# 增量概念文档


相比于[v1版本](../v1/PRD.md)，这里表述v2版本的增量更新。


## 灵动岛静息状态

原本灵动岛静息态不会完全收敛，而是替换为一个薄层。
薄层显示的内容取决于收敛灵动岛前，最后查看（选中）的功能卡。

我们重新规定灵动岛的三种状态：
- 静息：甚至不在屏幕上方渲染黑框
- 收敛：在屏幕上方显示厚度等于Mac摄像头盲区，宽度大于摄像头盲区的信息栏
- 展开：鼠标移动到岛上进入展开态，显示详细信息
* 提示：见下一小节。更像是一种即时动画。

v2开始，不是所有功能卡都有收敛态。比如pusher就只能有静息，展开或提示，没有收敛。


## 功能卡主动消息提示

当某个状态触发（比如timer计时任务结束），灵动岛会变大，展示醒目符号，告诉用户提示。持续6秒或用户鼠标移入后，提示效果结束。

提示排队显示(first in, frist display)。

提示的6秒结束后（用户期间没有鼠标干预），播放排队中的下一个提示或者回到提示触发前的状态。

灵动岛展开期间出现的消息也排队到展开态结束（用户鼠标移出）后1.5秒开始播放。


## CLI接入

本项目坚持单进程，由brew分发，brew -cask安装的应用程序。

但是现在允许Coding Agent使用CLI来管理一些功能卡片的状态，比如创建timer的每日计时任务，切换pusher某个任务的状态等等。

基础命令为
```bash
peeker --help # 展示peeker CLI的使用指示

peeker status # 展示peeker应用进程是不是存活
```

具体的模块接口示例
```bash
peeker timer start "work out" #开始work out计时任务

peeker timer list #检查目前所有计时任务列表以及完成状态
```
