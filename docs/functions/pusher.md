# 计划推进管理器


> 一个协助用户管理手头上需要推进的计划的工具

用户希望管理自己手头需要完成的任务，而不是keep missing一些工作。



## 配置页

在设置页可以编辑pusher功能的设置。包括

- 是否启动
- 未完成(不处于done状态)的任务是否顺延到下一天
- 每日任务刷新时间（默认每天0点，但是考虑到有些用户并不会在系统的0点入睡，因此可以自己调节如何定义新的一天）


## 任务列表

列表中的一项包括
- 急迫度：紧急(红) | 推进(蓝) | 规划(绿)
- 名称
- 是否为每日刷新


## 功能卡页

分为左侧(占80%)和右侧(占20%)。

### 左侧

分为3列

Planned | Processing | Done

每一栏下面分别放当前状态下激活的任务卡。

任务卡显示： 任务名称。卡本身的颜色表示急迫度。

鼠标移动到任务卡上改为显示“编辑”按钮。

### 右侧

放上下两个按钮。
- 新增：新增任务
- 日历：打开简易日历


## 新增/编辑任务卡

点击新增/编辑后，弹出一个任务编辑卡。

中间可以设置任务的名称，急迫度，是否每日刷新。

下方是两个按钮：取消/确认（确认创建或确认编辑）


## 简易日历

一个日历，上面是日期/当日完成任务的数量。

完成任务的数量统计方法为计时器刷新时，"Done"栏的任务数。
