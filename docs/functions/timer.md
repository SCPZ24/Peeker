# 计时器


> 一个督促用户完成每日自我监督的任务计时器。

用户希望给自己安排一些每日任务，每天督促自己推进一些工作。但是这些工作不一定会连续，不一定会一项做完以后再开启下一项。
比如用户的一天可以给自己安排：
- 健身2h
- 阅读1h
- 编程2h
- 思考30min

所以我们需要一个每天会自动刷新的计时器列表。

## 配置页

在设置页可以编辑timer功能的设置。包括

- 是否启用
- 显示完成度日历还是今日总完成度
- 编辑每日任务列表。列表中的一项包括
    - 坚持时长h/m/s
    - 名称
    - 显示颜色
- 计时器刷新时间（默认每天0点，但是考虑到有些用户并不会在系统的0点入睡，因此可以自己调节如何定义新的一天）


## 每日刷新和完成度

系统面板上，左边是今天的计时器列表(占岛的75%)，右边是完成度日历或者今日总完成度（环形展示，参考apple watch的健身时长记录）。

无论计时器完成了多少，第二天都按时刷新。


## 计时器

一个计时器列表一次只可以启动一个计时器。

用户选择暂停当前ticking的计时器后，才可以启动别的计时器。

因此用户的一天可能经历了
```plaintext
健身2h -> 编程1h -> 离开电脑 -> 思考30min -> 阅读30min -> 离开电脑 -> 编程1h -> 阅读30min
```
